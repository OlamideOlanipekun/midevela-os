# Purpose

The North Star defines the single principle that guides every product decision inside Midevela.

When priorities conflict, engineers, designers and product managers should return to this document before making decisions.

If a feature moves us closer to our North Star, we build it.

If it does not, we reconsider it.

---

# North Star Statement

> **We don't help people search websites.**

> **We help websites understand people.**

This statement defines Midevela.

We are not improving search.

We are replacing confusion with intelligent guidance.

---

# What This Means

Customers visit websites with goals.

Rarely do they visit with complete information.

Instead they arrive with uncertainty.

Examples include

"I need a laptop."

"I want a skincare routine."

"I need shoes."

"I'm looking for a CRM."

Most websites respond with:

Search.

Categories.

Filters.

Pagination.

Midevela responds with conversation.

Understanding.

Recommendations.

Confidence.

# Success Formula

Every interaction should increase one or more of the following:

- Customer understanding
- Buying confidence
- Purchase intent
- Trust
- Business knowledge
- AI intelligence

If an interaction increases none of these, it is not valuable.

---

# Product Decision Framework

Every new feature must answer these questions.

## Does it reduce confusion?

If not,
do not build it.

---

## Does it improve confidence?

If not,
do not build it.

---

## Does it shorten the buying journey?

If not,
reconsider it.

---

## Does it make the AI smarter?

If not,
its value is limited.

---

## Does it improve measurable business outcomes?

If not,
it is not a priority.

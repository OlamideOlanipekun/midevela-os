# Purpose

The Dashboard is the operating system for the business.

While customers interact with the AI, businesses interact with the Dashboard.

Its purpose is to provide visibility, control, insights, and configuration for every AI-powered interaction.

The Dashboard should answer one question:

> **"What is happening inside my business right now?"**

---

# Dashboard Philosophy

Traditional dashboards show reports.

Midevela's dashboard should help businesses make decisions.

Every screen should answer:

- What happened?
- Why did it happen?
- What should I do next?

The dashboard is an intelligent assistant—not a reporting tool.

# Conversations

Businesses can:

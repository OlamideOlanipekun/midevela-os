# Purpose
The Dashboard is the command center for every business using Midevela.
It provides a real-time overview of customers, AI performance, revenue, conversations, automations, and business health.
The dashboard is not a reporting page.
It is a decision-making workspace.
---
# Mission
Allow businesses to understand what is happening right now and know exactly what action to take next.
---
# Design Principles
The dashboard should feel like:
- Linear
- Stripe Dashboard
- Vercel
- Notion
- GitHub
Fast.
Minimal.
Information dense.
Never overwhelming.

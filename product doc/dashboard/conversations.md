# Purpose
The Conversations module is the unified inbox for every customer interaction across all supported channels.
Businesses should never need to switch platforms to communicate with customers.
---
# Mission
Provide one intelligent inbox for every customer conversation.
---
# Supported Channels
- Website Widget
- WhatsApp
- Instagram
- Facebook Messenger
- Email
Future:
- Telegram
- X
- TikTok
- SMS
---
# Inbox Layout
```text
-------------------------------------------------------
Conversation List
|
Conversation Window
|
Customer Intelligence Panel
-------------------------------------------------------
```
---
# Conversation List
Display:
- Customer name
- Channel
- Last message
- Buying Confidence
- Intent Score
- Assigned representative
- Status
- Unread count
---
# Conversation Window
Supports:
- Rich text
- Images
- Videos
- Product cards
- Buttons
- Checkout links
- File attachments
Messages stream in real time.
---
# Customer Intelligence Panel
Always visible.
Displays:
- Customer profile
- Purchase history
- Wishlist
- Buying Confidence
- Intent Score
- Lifetime value
- Previous conversations
- AI summary
---
# AI Assistant
AI continuously suggests:
- Replies
- Products
- Bundles
- Upsells
- FAQs
- Next best action
Agents can edit before sending.
---
# Human Handoff
Representatives can:
- Take over
- Return to AI
- Leave internal notes
- Reassign conversations
